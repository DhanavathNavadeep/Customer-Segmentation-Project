# Customer Segmentation Using K-Means Clustering

## Project Overview

This project uses K-Means Clustering to segment customers based on their annual income and spending behavior. Customer segmentation helps businesses identify different customer groups and create targeted marketing strategies.

## Objectives

* Analyze customer spending patterns.
* Perform customer segmentation using K-Means Clustering.
* Determine the optimal number of clusters using the Elbow Method.
* Visualize customer groups using scatter plots.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

## Dataset Features

The dataset contains the following attributes:

* CustomerID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1-100)

## Project Workflow

1. Load customer dataset.
2. Clean and preprocess data.
3. Select Annual Income and Spending Score features.
4. Scale the data using StandardScaler.
5. Use the Elbow Method to find the optimal number of clusters.
6. Apply K-Means Clustering.
7. Visualize customer segments.
8. Export segmented customer data.

## Results

* Successfully segmented customers into multiple groups.
* Generated an Elbow Method chart for cluster selection.
* Created a customer segmentation visualization.
* Produced clustered customer data for business analysis.
